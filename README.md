# Sistema de Asientos de Cine 🎬

Sistema de consola desarrollado en C# para la gestión, reserva, cancelación y visualización de estadísticas de ocupación en una sala de cine.

## Integrantes del Equipo
* **César Lenny Chávez Mojica**
* **Javier Sebastián Chautla Guadarrama**

## Funcionalidades del Sistema
* Mostrar mapa actual de la sala de cine ('L' para Libre, 'X' para Ocupado).
* Módulo de reserva de asientos por coordenadas de fila y columna.
* Módulo de cancelación de reservas activas.
* Reporte de estadísticas y porcentaje de ocupación de la sala en tiempo real.
